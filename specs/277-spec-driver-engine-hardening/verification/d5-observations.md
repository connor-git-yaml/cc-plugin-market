## 观察协议

判定对象 = 被派发的长文档子代理**是否自发**按块 1 的协议先落骨架、再逐节 `Edit` 填充。

### 三条观察纪律（缺一条则该次观察作废，不计入分子也不计入分母）

1. **委派 prompt 中不得提及**分节协议 / 骨架 / 逐节 `Edit` / 「先落盘再填」/ 「不要一次性写完」或任何等价要求。
   一旦提示，测到的就只是「被明确要求时能做到」，与本 Story 的命题（协议注入后子代理**自发**遵守）自相矛盾。
2. 必须是**不同文档、不同会话**的真实长文档生成。
   **不得**为凑数在 Phase E 集中造 3 次，也不得把同一份文档的 3 次续写记作 3 次独立观察。
3. 每次观察须记录**骨架与已完成节的字节比对结果**（判据同块 1 §中断幸存与按段续写：判定标志是**字节**变化，不是行数、不是相似度、不是语义等价），并附产生该结论的**命令原文与原始输出**。

### 每条观察的记录格式

| 字段 | 填写口径 |
|---|---|
| 观察序号 | 1 / 2 / 3 …（按发生顺序） |
| 日期与会话 | 须与其余观察不同会话 |
| 被观察的委派 | 子代理类型 + 产出文档路径 |
| prompt 未提示协议的证据 | 委派 prompt 中相关关键词的检索命令原文与其**原始输出**（期望为空） |
| 首次落盘形态 | 「骨架 + 占位行」/「一次性长 Write 全文」/「其他（写明）」 |
| 字节比对命令与原始输出 | 如 `diff <快照> <当前文件>` 或逐节 `sha256sum` 的命令原文与输出 |
| 已完成节字节是否变化 | 是 / 否；「是」即判发生整篇重写 |
| 本次是否计入分子 | 计入条件 = 首次落盘为骨架形态**且**后续续写未改动已完成节字节 |

## Phase E 汇总口径（本条只开窗口、不汇总）

- 换算式：**自发分节落盘次数 ÷ 独立观察次数 = 3 ÷ 3 = 100%**（单位：观察次），N ≥ 3 为下界。
- 出现 **1 次**一次性长 Write 即判 D-5 未达成，并**如实记录比例（如 2/3）**，**不得**四舍五入为通过、不得以「另两次都对」总括为达成。
- 观察次数不足 3 次时判「未执行（缺席）」，**不得**以「已建立窗口」替代观察本身。
