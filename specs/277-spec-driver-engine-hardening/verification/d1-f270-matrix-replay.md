### 通过意味着什么 / 不意味着什么（诚实边界收口）

**意味着**：T037 定稿的 `## FR → Phase 覆盖矩阵` + `## 裁剪登记` 两个必选区块，**在 F270 这个真实历史语料上具备捕获力**——按规则逐行填完 49 行，`未认领 + 无裁剪登记` 的组合会在 plan 阶段就把 F270 全部 over-claim 的结构性根源顶到台面上，且不会把有认领的 FR 误伤成未认领。

**不意味着**（逐条对应本文件开头的诚实边界）：

1. **不意味着规则已自动生效**。本回放是**人工按判据推演**，不是机械执行；矩阵的 49 行由人逐条判读得出，判读中的两处宽松取舍（判读留痕 N-1 / N-2）若改从严，未认领数将从 12 升至 14。**阳性结论对这两处取舍不敏感**（4 组全在从严侧亦成立），但已认领方向的计数敏感。
2. **不意味着规则能挡住蓄意规避**。本回放验证的是「**认真填表就能发现**」，不是「**填表者想藏也藏不住**」。填表者若把未认领行直接省略、或给未认领 FR 编一个 Phase 名，规则文本里的两条兜底（R1「不允许省略未认领行」、R5「取值不在集合内一律判失去认领」）目前**只有文字约束、无机械校验**——F270 的真实失效正是「plan 里根本没有这张表」，而不是「表填错了」。
3. **不意味着分母口径问题已解决**。本回放把分母钉在 H-1 原文全集的 4 组，但机械回放另抓出 4 条（FR-020 / FR-021 / FR-036 / FR-042），说明**连事后补登的「全集」也不是全集**。任何以「自己选取的项数」作分母的捕获率都可被同一手法收窄——这条对本文件自身同样适用。
